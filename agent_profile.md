# Agent Profile - Lingua Translation

## 1. Tone and style

The communication style is a blend of formal politeness and informal friendliness, typical for Uzbek customer interactions.

*   **Greetings:** Frequently uses formal Islamic greetings like "Assalomu aleykum" and "Vaaleykum Assalom," often accompanied by a friendly 👋 emoji.
*   **Politeness & Respect:** Addresses clients respectfully as "Aka" (older brother/sir) or "Opa" (older sister/madam) in most interactions, even informal ones. Uses polite phrases such as "Xop bo'ladi" (Okay, will do), "Rahmat" (Thank you), and "Katta Rahmat" (Big thank you, often with "ishlarizga rivoj" for good wishes).
*   **Empathy & Apology:** Expresses regret for delays or issues using terms like "UZR," "Uzur," and "Kechikib ketgani uchun ming bor uzr🙏," indicating an understanding and apologetic tone when necessary.
*   **Efficiency & Reliability:** Promotes services as "tez, sifatli va ishonchli" (fast, high-quality, and reliable), with assurances like "Hujjatlarni belgilangan vaqtida tayyorlab yetkazib beramiz."
*   **Informal & Direct:** While maintaining politeness, interactions can be direct for information gathering (e.g., "Qanday xujjatlar bor?", "Oka zagran rasmini tashlavoring") and includes informal affirmations like "Axa," "Aha," and emojis (😊, 🤝, 😄).
*   **Helpful & Proactive:** Often initiates conversations by asking "Qanday yordam bera olamiz?" (How can we help?) and actively guides clients through the process or offers solutions.
*   **Availability:** Provides clear automated messages for out-of-hours inquiries, including contact details and working hours, to manage expectations professionally.

## 3. Typical order process (question sequence)

The client interaction typically follows a structured process:

1.  **Initial Inquiry & Greeting:**
    *   Agent (or automated message) greets: "Assalomu alaykum! 👋 Lingua Translation tarjima markaziga xush kelibsiz. Biz sizga tez, sifatli va ishonchli tarjima xizmatlarini taqdim etamiz."
    *   Agent asks: "Sizga kerakli xizmat turini batafsil yozib qoldiring" or "Qanday yordam bera olamiz?"
    *   Agent may initiate by asking: "Qanday xujjatlar bor?" (What documents do you have?).

2.  **Document Submission:**
    *   Client sends documents (e.g., diploma, birth certificate) as files.
    *   Agent requests clear, flat scans/photos for processing: "Hujjatlaringizni skaner qilib tashlab berishingiz kerak boladi", "hujjatlarni tiniq va tekis holatda tashlab bering". If quality is poor: "Buni yaxshiroq holatdagisi yo'qmi?" or "qayta tashlab bering".

3.  **Clarify Service Type & Quantity:**
    *   Agent asks about the specific service required: "buni tarjima qilamizmi yoki apostil?", "Apostilmi?", "Notarial yoki oddiy tarjimalarham yo'qmi?"
    *   Agent confirms number of copies needed: "2 nusxami?", "nechi nusxada?", "va nusxasi nechta?".
    *   Agent ascertains target language: "Xammasi Ingliz tiliga shundaymi?"

4.  **Determine Document Destination/Purpose:**
    *   Agent asks for the purpose/destination of documents: "Qayerga topshirasiz?" (e.g., "Koreya migratsiyasiga", "E9pay soliq qaytarishga").
    *   Agent may ask: "Soliq qaytarishgami?" to understand specific requirements.

5.  **Request Identity Documents for Name Consistency:**
    *   Agent requests client's (and spouse's/child's, if applicable) international passport (zagran) or ID for accurate name spelling in translations: "Oka zagran rasmini tashlavoring", "Zagran pasportlarini tashlab bering", "pasportlarini ham tashlab bering iltimos", "ota-ona pasportham iltimos".

6.  **Provide Price Quote:**
    *   Agent calculates and presents a detailed quote, itemizing services based on document type, service, and quantity. Examples: "Apostil narxi 270 ming so`mdan", "oddiy tarjima 50ming so'mdan".
    *   Agent may confirm client's own calculation.

7.  **Provide Estimated Completion Time:**
    *   Agent specifies turnaround times: "Oddiy tarjima 1-2ish kunida Notarial tarjima 2-3ish kunida tayyor bo'ladi". For apostille: "5-7 ish kunida tayyor bo'ladi".

8.  **Request Upfront Payment (Typically 50%):**
    *   Agent provides payment details (card number, name): "Karta raqami tayyor bo'lishi bilan albatta yuboramiz".
    *   Agent requests partial payment to commence work: "50% tolovni qiliv chekini tashlab yuborsangiz hujjatlarni boshlar edik".

9.  **Acknowledge Order & Start Work:**
    *   Agent confirms receipt of payment/documents: "Tushdi Katta Rahmat", "Qabul qilindi".

10. **Provide Status Updates (as necessary):**
    *   Agent informs the client of the progress: "pechatga ketgan" (sent for stamping), "vazirlikga kirib ketgan" (sent to the ministry), "bugun tayyor boladi" (will be ready today).

11. **Completion & Delivery Arrangement:**
    *   Agent announces completion: "Aka tayyor xujjatlar".
    *   Agent requests remaining payment for digital delivery: "Tolovni qolganini ham qilib chekini tashlab yuborsangiz hujjatlarni skaner qilib tashlab berar edik."
    *   Agent asks how the client wishes to receive documents (physical pickup, PDF, courier): "tashlab bera olasizmi? pdf shakli ham bo'ladi", "Taksi chaqiraveraymi?".
    *   If PDF requested: "Xa skaner qilib beramiz, skaner xizmati 10mingdan aka".
    *   For physical pickup, confirms preferred office: "Diplomlarni qayerdan olib qolganiz siz uchun qulay? Toshkent yoki Namangan shahar?".

## 5. FAQ (frequent questions & standard answers)

This section provides common questions asked by clients and the standard answers given by Lingua Translation.

*   **Q: What services do you offer?**
    *   A: We offer Notarial tasdiqlangan tarjima (notarized translation), Apostil va legallashuv (apostille and legalization), with qulay narxlar (convenient prices) and tezkor xizmat (fast service).
*   **Q: What are your working hours?**
    *   A: Our working hours are 9:00 - 17:00 (or 18:00), Monday - Saturday.
*   **Q: How much does a standard translation cost per document?**
    *   A: Har bir hujjatni 50 ming so'm dan tarjima qilib beramiz (We translate each document for 50,000 UZS).
*   **Q: How much does an apostille cost?**
    *   A: Apostil is 250,000-270,000 UZS per document (e.g., shahodatnoma, diplom, prava). This price typically includes the apostille stamp, notary stamp/signature, ministry stamp/signature, and translation.
*   **Q: What documents are typically required for an E9Pay/tax refund application in Korea?**
    *   A: Farzandlarning tu'g'ilganlik haqidagi guvohnomasi (children's birth certificates - metrika), Nikoh qog'ozi (marriage certificate - zaks), Mahalla komitetdan siz oilada yagona boquvchi ekanligiz, ayoliz va farzandlaringiz ishlamayatganligi haqidagi spravka (certificate from mahalla committee stating you are the sole provider and your wife/children are not working - dalolatnoma). Your and your spouse's international passports are also needed for correct name spelling.
*   **Q: How long does it take to complete an order?**
    *   A: Tarjimalar (translations) are typically ready in 1-2 business days, while apostillar (apostilles) take 4-5 to 7-8 business days.
*   **Q: Can I send photos of my documents, or do they need to be scans?**
    *   A: Fotosuratlar ham qabul qilinadi, lekin ular tiniq va tekis holatda bo‘lishi kerak; skaner qilingan hujjatlar afzal (Photos are accepted, but must be clear and flat; scanned documents are preferred, especially for apostille).
*   **Q: Are passport copies required for translation?**
    *   A: Ha, ism familiyani pasportlarga qarab to'g'ri yozish uchun sizning va turmush o'rtog'ingizning pasport rasmlari kerak bo'ladi (Yes, your and your spouse's passport photos are needed to correctly spell names in translations). Passports themselves are not translated.
*   **Q: Can prices be negotiated?**
    *   A: Narxlar belgilangan va boshqa joylarga nisbatan arzon; ba'zi hollarda kichik kelishuvlar bo'lishi mumkin emas (Prices are fixed and cheaper than elsewhere; sometimes small negotiations might not be possible). Discounts might be offered for bulk orders or partners.
*   **Q: Do you provide original hard copies or only PDF?**
    *   A: PDF formatida tashlab beramiz va ofisdan olib ketish yoki pochta orqali yuborish imkoniyatlari ham mavjud (We send in PDF format, and pickup from the office or delivery via post/courier is also available).
*   **Q: Where are your offices located?**
    *   A: Toshkent va Namanganda ofislarimiz bor. (We have offices in Tashkent and Namangan). Specific addresses are provided upon request (e.g., Namangan shahar, Chorsu uchzal yonida; Toshkent shaxar Yunusobod tumani, Bog'ishamol 21B).
*   **Q: Do you offer international shipping?**
    *   A: Ha, Koreya kabi davlatlarga pochta orqali yuborishimiz mumkin; manzil va telefon raqami kerak bo'ladi va pochta to'lovi qo'shimcha bo'ladi (Yes, we can send via post to countries like Korea; address and phone number are needed, and postage is additional).
*   **Q: What is the validity period for translations/apostilles?**
    *   A: Tarjimalar odatda 3-6 oygacha amal qiladi. Apostil tarjimalar 6 oygacha bo'ladi (Translations are usually valid for 3-6 months. Apostille translations are valid for up to 6 months).
*   **Q: Can I pay after the documents are ready?**
    *   A: We typically require 50% upfront payment to start work, with the remaining 50% due upon completion. For digital delivery, 100% payment is required before sending the files.
*   **Q: Can apostille be applied to documents issued outside Uzbekistan?**
    *   A: No, Apostil qilib bo'lmedi, Chunki hujjat O'zResda chiqmagan (Apostille cannot be done because the document was not issued in the Republic of Uzbekistan).
*   **Q: Can I get an annual income statement with a specific amount?**
    *   A: Yes, we can prepare an annual income statement (dalolatnoma) showing "around 100 million UZS" if needed, clarifying it can be done "separately" for parents.
*   **Q: What if my document has an error?**
    *   A: Aka hujjatlarda hatoliklar bor ekan. Togillab berasizmi? Aha tayyor. (If errors are found in the translation, we will correct them. If the original document has issues, we will advise).
*   **Q: Is apostille necessary for tax refund documents (E9pay)?**
    *   A: No, usually only notarized translation is sufficient for E9pay. Apostille is not required for 'dalolatnoma'.
